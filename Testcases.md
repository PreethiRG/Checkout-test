# Login Test Cases

## TC001: Valid Login

**Test Scenario:** Verify login with valid credentials.

**Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the Login button.

**Expected Result:** The user should log in successfully.

## TC002: Invalid Password

**Test Scenario:** Verify login with an invalid password.

**Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter an incorrect password.
4. Click the Login button.

**Expected Result:** An appropriate error message should be displayed.

## TC003: Empty Login Fields

**Test Scenario:** Verify login with empty username and password fields.

**Steps:**
1. Open the login page.
2. Leave both fields empty.
3. Click the Login button.

**Expected Result:** Appropriate validation messages should be displayed.
